# Product

## Register

product

## Users

Single admin (personal use) managing family and personal events like birthdays, name days, and holidays. Context: checking upcoming events, adding new reminders, editing existing ones. Casual, infrequent use rather than daily workflow.

## Product Purpose

Remindly helps track important personal dates and recurring events. It provides a public API for querying upcoming events and an admin interface for managing them. Success means never missing a birthday or holiday again.

## Brand Personality

Warm, friendly, approachable. Like a helpful personal assistant, not a corporate tool. Welcoming when you open it, easy to scan at a glance, pleasant to use for quick tasks.

## Anti-references

- Corporate SaaS dashboards (sterile gray-blue, enterprise feel)
- Overly playful or cartoon-like designs (keep it mature)
- Dark mode heavy interfaces (prefer light and airy)

## Design Principles

- **Clarity over cleverness**: Event information should be instantly scannable
- **Warmth through color and typography**: Friendly doesn't mean childish
- **Respect the content**: Events are the focus, not decorative elements
- **Effortless interactions**: Forms and navigation should feel natural, not technical

## Accessibility & Inclusion

Standard WCAG AA compliance. Good contrast ratios, readable text sizes, keyboard navigation support.
